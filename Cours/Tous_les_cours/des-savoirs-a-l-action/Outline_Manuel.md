Voici le **nouvel outline détaillé** du manuel *Des savoirs à l’action*, réaligné sur le standard UCKK :

> **Orienter → Situer → Distinguer → Transformer → Produire → Évaluer → Mémoriser → Projeter → Référencer**

Le manuel reste organisé en **18 chapitres**, mais chaque chapitre suit maintenant une logique plus nette : **Situer → Distinguer → Transformer → Produire → Retenir → Référencer**. L’outline reprend le plan déjà élaboré, la bibliographie commentée et les flows kOA autour des passages contrôlés entre connaissance, choix, action et mémoire.

# 01. Introduction générale

## Fonction UCKK dominante

**Orienter**

## 1. Situer

Présenter le guide comme une méthode pour transformer une situation, un besoin ou un dossier existant en piste d’action responsable.

Expliquer que le guide ne sert pas à imposer une solution, mais à apprendre à :

* observer ;
* écouter ;
* distinguer ;
* choisir ;
* agir ;
* mémoriser ;
* transmettre prudemment.

## 2. Distinguer

Clarifier ce que le guide n’est pas :

* pas un manuel sur les cultures autochtones ;
* pas un protocole universel ;
* pas un outil d’extraction des savoirs ;
* pas une procédure pour décider à la place des personnes concernées ;
* pas un document kOA ;
* pas un manuel technique sur l’IA.

## 3. Transformer

Présenter la transformation centrale :

```text
information dispersée
→ compréhension prudente
→ choix justifié
→ action responsable
→ mémoire utile
```

## 4. Produire

Présenter le travail final en une page :

L’étudiant devra transformer une situation ou un dossier dormant en piste d’action responsable.

## 5. Retenir

Phrase clé :

> Le but n’est pas de produire une réponse parfaite. Le but est de produire une démarche claire, prudente, révisable et utile.

## 6. Référencer

Références à mentionner discrètement :

* Smith ;
* Wilson ;
* Kovach ;
* Tuck & Yang ;
* EPTC 2 ;
* OCAP® ;
* CARE.

# 02. Commencer par ce qui existe déjà

## Fonction UCKK dominante

**Situer**

## 1. Situer

Présenter l’idée que beaucoup de démarches commencent par les problèmes, les manques ou les urgences.

Ce chapitre propose un renversement :

> Avant de demander “qu’est-ce qui manque ?”, demander “qu’est-ce qui existe déjà ?”

## 2. Distinguer

Distinguer :

* problème et contexte ;
* manque et ressource ;
* vulnérabilité et capacité ;
* besoin et potentiel ;
* urgence visible et force invisible.

## 3. Transformer

Transformer le regard de l’étudiant :

```text
diagnostic par les manques
→ reconnaissance des ressources déjà présentes
```

## 4. Produire

Mini-exercice :

À partir d’une situation choisie, écrire deux descriptions :

1. une description centrée sur les problèmes ;
2. une description centrée sur les ressources déjà présentes.

Comparer les effets des deux descriptions.

## 5. Retenir

Phrase clé :

> Une communauté ne doit pas être décrite seulement par ses manques.

## 6. Référencer

Références principales :

* Kretzmann & McKnight ;
* Eve Tuck ;
* Smith.

# 04. Écouter avec attention

## Fonction UCKK dominante

**Distinguer → Transformer**

## 1. Situer

Présenter l’écoute comme une pratique active, pas comme une attente passive.

Les paroles, gestes, silences et contextes ont une profondeur qu’on ne peut pas saisir immédiatement.

## 2. Distinguer

Distinguer :

* entendre et écouter ;
* parole et interprétation ;
* silence et consentement ;
* refus et obstacle ;
* observation et conclusion.

## 3. Transformer

Transformer l’écoute en méthode :

```text
parole reçue
→ observation prudente
→ questions ouvertes
→ interprétations à vérifier
```

## 4. Produire

Tableau d’écoute :

| Ce qui est dit | Ce qui est observé | Contexte | Ce que je crois comprendre | Ce que je dois vérifier | Ce que je ne comprends pas encore |
| -------------- | ------------------ | -------- | -------------------------- | ----------------------- | --------------------------------- |

Mini-exercice :

Écouter une personne décrire une situation, puis noter :

* trois paroles exactes ;
* deux observations ;
* deux interprétations possibles ;
* trois questions ouvertes ;
* une limite de partage.

## 5. Retenir

Phrase clé :

> Pendant que quelqu’un parle, le travail n’est pas de conclure. Le travail est d’écouter.

## 6. Référencer

Références principales :

* Rogers & Farson ;
* Wilson ;
* Kovach ;
* Audra Simpson.

# 05. Distinguer faits, hypothèses et interprétations

## Fonction UCKK dominante

**Distinguer**

## 1. Situer

Expliquer que les erreurs commencent souvent quand on confond ce qui est observé, supposé, interprété et décidé.

## 2. Distinguer

Définir :

| Terme          | Définition                       |
| -------------- | -------------------------------- |
| Fait           | Élément vérifiable               |
| Hypothèse      | Possibilité à confirmer          |
| Interprétation | Sens donné à une situation       |
| Décision       | Orientation choisie après examen |
| Incertitude    | Élément qui reste ouvert         |

## 3. Transformer

Transformer des notes confuses en carte de compréhension.

```text
énoncés dispersés
→ faits / hypothèses / interprétations / décisions
→ questions à vérifier
```

## 4. Produire

Tableau :

| Énoncé | Fait | Hypothèse | Interprétation | Décision | À vérifier |
| ------ | ---: | --------: | -------------: | -------: | ---------- |

Mini-exercice :

Classer 10 énoncés tirés de la situation étudiée.

## 5. Retenir

Phrase clé :

> Comprendre, c’est aussi savoir nommer ce qui manque à notre compréhension.

## 6. Référencer

Références principales :

* Schön ;
* Smith ;

# 07. Ne pas courir vers la première solution

## Fonction UCKK dominante

**Distinguer**

## 1. Situer

Présenter le réflexe de solution rapide : vouloir agir pour réduire l’inconfort, montrer son efficacité ou répondre à la pression.

## 2. Distinguer

Distinguer :

* action rapide et action utile ;
* urgence réelle et urgence ressentie ;
* solution familière et solution responsable ;
* ne pas agir tout de suite et rester passif.

## 3. Transformer

Transformer l’impulsion de solution en pause méthodique.

```text
solution immédiate
→ ralentissement
→ exploration des options
```

## 4. Produire

Mini-exercice :

Nommer la première solution qui vient à l’esprit, puis écrire :

* pourquoi elle paraît évidente ;
* ce qu’elle risque de cacher ;
* qui devrait être consulté avant de la retenir.

## 5. Retenir

Phrase clé :

> Une solution rapide peut rassurer, mais elle peut aussi fermer trop tôt le champ des possibles.

## 6. Référencer

Références principales :

* Dryzek ;
* Fishkin ;
* Schön.

# 10. Choisir sous contrainte de temps

## Fonction UCKK dominante

**Transformer → Évaluer**

## 1. Situer

Il faut explorer assez pour éviter la précipitation, mais il n’existe jamais un temps infini pour décider.

## 2. Distinguer

Distinguer :

* choix provisoire ;
* choix final ;
* choix à valider ;
* urgence réelle ;
* urgence organisationnelle ;
* urgence émotionnelle ;
* urgence politique.

## 3. Transformer

Transformer une comparaison en décision prudente.

```text
options comparées
→ choix explicable
→ conditions de révision
```

## 4. Produire

Formule de décision :

```text
Nous retenons l’option ___ parce que ___.
Nous ne retenons pas ___ pour l’instant parce que ___.
Cette décision est limitée par ___.
Elle devra être révisée si ___.
Avant d’agir, il faut consulter ou valider auprès de ___.
```

## 5. Retenir

Phrase clé :

> Une bonne décision est assez claire pour agir et assez humble pour être révisée.

## 6. Référencer

Références principales :

* Fishkin ;
* Dryzek ;
* Graham et al.

# 12. Transformer une décision en action

## Fonction UCKK dominante

**Transformer**

## 1. Situer

Une décision devient réelle seulement lorsqu’elle est traduite en responsabilités, étapes, ressources, échéances et suivis.

## 2. Distinguer

Distinguer :

* décision et action ;
* intention et responsabilité ;
* plan ambitieux et premier geste réaliste ;
* action avec les personnes et action pour les personnes.

## 3. Transformer

Transformer un choix en plan d’action minimal.

```text
choix justifié
→ seuil d’action
→ responsabilités visibles
→ premier geste
```

## 4. Produire

Tableau :

| Action | Responsable | Ressources nécessaires | Première étape | Échéance | Suivi |
| ------ | ----------- | ---------------------- | -------------- | -------- | ----- |

Tableau des responsabilités :

| Rôle | Personne ou groupe | Responsabilité | Moment d’intervention | Limite du rôle |
| ---- | ------------------ | -------------- | --------------------- | -------------- |

## 5. Retenir

Phrase clé :

> Une décision sans responsabilité reste une intention.

## 6. Référencer

# 15. Reconnaître les savoirs dormants

## Fonction UCKK dominante

**Mémoriser**

## 1. Situer

Définir le savoir dormant comme une information, expérience, trace ou document qui existe déjà, mais qui n’est plus activement utilisé.

## 2. Distinguer

Distinguer quatre statuts :

| Statut           | Description                     | Ce qu’on peut faire                    |
| ---------------- | ------------------------------- | -------------------------------------- |
| Utilisable       | Clair, validé, partageable      | Transformer en outil ou action         |
| À vérifier       | Utile mais incertain            | Identifier les validations nécessaires |
| Sensible         | Délicat ou limité               | Restreindre l’accès                    |
| Non réutilisable | Trop incertain ou hors contexte | Ne pas utiliser pour l’action          |

## 3. Transformer

Transformer une archive vague en dossier identifié.

```text
document oublié
→ origine
→ contexte
→ statut
→ limites
→ vérifications
```

## 4. Produire

Fiche :

| Élément                              | Réponse |
| ------------------------------------ | ------- |
| Titre ou description du dossier      |         |
| Type de document                     |         |
| Date approximative                   |         |
| Origine connue ?                     |         |
| Personnes ou groupes concernés       |         |
| Pourquoi ce dossier est-il dormant ? |         |
| Ce qui semble encore utile           |         |
| Ce qui semble sensible               |         |
| Ce qui doit être vérifié             |         |
| Première action possible             |         |

## 5. Retenir

Phrase clé :

> Disponible ne veut pas dire utilisable.

## 6. Référencer

Références principales :

* Graham et al. ;
* CIHR ;
* Gebru et al. ;
* OCAP® ;
* CARE.

# 16. Transformer un dossier en information actionnable

**Transformer → Produire**

## 1. Situer

Lire un dossier ne suffit pas. Il faut le relire selon une question pratique :

## 2. Distinguer

Distinguer :

* information brute ;
* interprétation ;
* action possible ;
* information dépassée ;
* information sensible ;
* absence importante ;
* risque de mauvaise lecture.

## 3. Transformer

Transformer un dossier dormant en information actionnable.

```text
dossier existant
→ éléments utiles
→ absences
→ risques
→ vérifications
→ action possible
```

## 4. Produire

# 18. Synthèse, travail final et conclusion

## Fonction UCKK dominante

**Produire → Évaluer → Référencer**

## 1. Situer

Rappeler les neuf gestes du guide :

1. identifier une situation ;
2. inventorier les ressources ;
3. écouter et observer ;
4. distinguer faits, hypothèses et interprétations ;
5. explorer plusieurs solutions ;
6. choisir sous contrainte de temps ;
7. prévoir les impacts ;
8. poser un premier geste responsable ;
9. garder une mémoire utile.

## 2. Distinguer

Clarifier ce que le travail final doit démontrer :

* pas une solution parfaite ;
* pas une vérité finale ;
* pas une analyse abstraite ;
* pas une collecte d’information ;
* mais une démarche prudente, traçable et révisable.

## 3. Transformer

Transformer tous les apprentissages en travail final :

```text
situation ou dossier
→ ressources
→ écoute
→ compréhension
→ options
→ choix
→ impacts
→ action
→ mémoire
```

## 4. Produire

Structure du travail final :

1. situation choisie ;
2. inventaire des ressources ;
3. écoute et observation ;
4. faits, hypothèses et interprétations ;
5. inventaire des solutions ;
6. choix justifié ;
7. prévision des impacts ;
8. plan d’action minimal ;
9. dossier dormant ou information existante ;
10. mémoire utile ;
11. retour réflexif.

Grille d’autoévaluation :

| Critère                                             | Oui | Partiellement | Non | Notes |
| --------------------------------------------------- | --: | ------------: | --: | ----- |
| J’ai identifié une situation claire                 |     |               |     |       |
| J’ai inventorié les ressources avant de conclure    |     |               |     |       |
| J’ai écouté sans prétendre tout comprendre          |     |               |     |       |
| J’ai distingué faits, hypothèses et interprétations |     |               |     |       |
| J’ai exploré plusieurs solutions                    |     |               |     |       |
| J’ai justifié mon choix                             |     |               |     |       |
| J’ai prévu plusieurs impacts possibles              |     |               |     |       |
| J’ai proposé un premier geste réaliste              |     |               |     |       |
| J’ai identifié ce qui doit être vérifié             |     |               |     |       |
| J’ai identifié ce qui doit rester protégé           |     |               |     |       |
| J’ai produit une mémoire utile                      |     |               |     |       |

## 5. Retenir

Phrase finale :

> Le but n’est pas de produire une réponse parfaite. Le but est de produire une démarche claire, prudente, révisable et utile.

## 6. Référencer

Rappel général :

Le travail final mobilise l’ensemble des références du guide. Voir la bibliographie commentée pour les références complètes.

# Standard appliqué à chaque chapitre

Chaque chapitre doit maintenant être rédigé selon ce modèle :

```markdown
# Chapitre X — Titre

## 1. Situer
Contexte, enjeu, problème de départ.

## 2. Distinguer
Concepts à ne pas confondre.

## 3. Transformer
Opération que l’étudiant apprend à faire.

## 4. Produire
Fiche, tableau, exercice ou livrable.

## 5. Retenir
Phrase clé, erreurs fréquentes, vigilance.

## 6. Référencer
Références mobilisées. Voir la bibliographie commentée.
```

Ce modèle rend le manuel plus stable, plus navigable et plus conforme à la signature pédagogique UCKK.
