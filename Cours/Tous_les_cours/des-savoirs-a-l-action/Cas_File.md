# Cas filé principal

## **Le Grand Dossier COVID — Autopsie d’une gestion de crise**

### Formule pédagogique

> Une crise mal gouvernée devient utile seulement si l’on transforme ses erreurs en mémoire active.

### Positionnement UCKK

Ce cas est assumé comme **critique, polarisant et méthodique**.
Il ne cherche pas à être neutre au sens faible. Il cherche à être **lucide, documenté, contestable et formateur**.

L’UCKK assume le théâtre public, la critique systémique et l’apprentissage par cas réels, mais avec une règle : la provocation doit éclairer, pas manipuler. Le document fondateur précise que l’esprit de l’UCKK peut être spectaculaire, mais que sa méthode doit rester rigoureuse.  Le branding insiste aussi sur l’équilibre : spectaculaire, mais rigoureux ; critique, mais constructif ; mythique, mais non dogmatique. 

---

# Description générale du cas

```markdown
La pandémie de COVID sert de cas filé critique pour apprendre à transformer une crise collective en mémoire utile.

Le cas part d’un constat : la gestion de la pandémie a révélé des faiblesses majeures dans la manière dont les institutions connaissent, choisissent, agissent et se souviennent.

Pendant la crise, les décisions ont souvent été prises dans l’urgence, avec des données incomplètes, des messages changeants, des conflits d’expertise, des impacts mal anticipés et des effets sociaux profonds.

Après la crise, de nombreux documents existent : consignes, rapports, statistiques, plaintes, témoignages, notes internes, plans d’urgence, bilans scolaires, données de santé mentale, recommandations et critiques publiques.

Mais ces informations restent dispersées. Certaines sont utiles. Certaines sont sensibles. Certaines sont contestées. Certaines sont oubliées. Certaines doivent être protégées. Certaines devraient devenir actionnables.

Le travail du cours consiste à reprendre ce Grand Dossier COVID pour comprendre ce qui s’est passé, distinguer faits et interprétations, comparer les options, prévoir les impacts, reconnaître les erreurs, et transformer cette crise en mémoire active pour mieux agir la prochaine fois.
```

---

# Règle de méthode du cas

À répéter dans le manuel :

> La critique est permise. L’accusation doit être documentée. L’indignation doit être transformée en méthode.

Cette règle correspond bien aux principes kOA : lucidité radicale, distinction entre faits, hypothèses, valeurs et récits, correction des erreurs et apprentissage continu.

# Le cas filé dans les 18 chapitres

## 01. Introduction générale

### Rôle du cas

Présenter le Grand Dossier COVID comme cas central du manuel.

* les ressources disponibles avant la crise ;
* les voix entendues ou ignorées ;
* les faits établis ;
* les hypothèses utilisées pour décider ;
* les interprétations imposées publiquement ;
* les solutions non comparées ;
* les impacts collatéraux ;
* les erreurs de suivi ;
* les dossiers dormants ;
* la mémoire institutionnelle insuffisante.

### Formulation à intégrer

```markdown
Ce guide utilise le Grand Dossier COVID comme cas filé. Le but n’est pas de trancher toutes les controverses médicales ou politiques, mais d’étudier une crise réelle où les sociétés ont dû connaître rapidement, choisir sous pression, agir à grande échelle et se souvenir de ce qui a été appris.

Le cas part d’une hypothèse critique : la gestion de la pandémie a produit des erreurs importantes de préparation, de communication, de proportionnalité, d’écoute, de suivi des impacts et de mémoire institutionnelle.
```

## 02. Commencer par ce qui existe déjà

### Rôle du cas

Avant de dénoncer la mauvaise gestion, on demande :

> Quelles ressources existaient déjà avant la crise ?

L’objectif est d’éviter une critique trop simple du type :

> “Rien n’était prêt.”

La vraie question est plus forte :

> Qu’est-ce qui existait déjà, mais a été mal vu, mal mobilisé, mal coordonné ou mal respecté ?

### Ressources à repérer

* plans de pandémie existants ;
* santé publique ;
* médecins de terrain ;
* infirmières ;
* pharmaciens ;
* écoles ;
* organismes communautaires ;
* familles ;
* municipalités ;
* radios locales ;
* réseaux de bénévoles ;
* savoirs issus d’épidémies précédentes ;
* données hospitalières ;
* lieux de distribution ;
* équipes logistiques ;
* experts critiques ;
* expériences locales.

### Exercice

Écrire deux descriptions.

#### Description A — Par les problèmes

> La crise a été mal gérée : confusion, règles contradictoires, fermetures, isolement, perte de confiance.

#### Description B — Par les ressources

> Avant et pendant la crise, plusieurs ressources existaient : réseaux de soins, écoles, organismes locaux, médecins, familles, lieux communautaires, plans d’urgence, expériences passées, mais elles n’ont pas toujours été coordonnées ou entendues.

### Phrase à retenir

> Une mauvaise gestion n’est pas toujours l’absence de ressources ; c’est souvent l’échec à les reconnaître, les coordonner ou les respecter.

## 04. Écouter avec attention

### Rôle du cas

La crise COVID est parfaite pour montrer que plusieurs voix peuvent être vraies partiellement, contradictoires et toutes importantes.

### Voix à écouter

* aînés isolés ;
* jeunes en décrochage ;
* parents épuisés ;
* soignants débordés ;
* enseignants ;
* travailleurs essentiels ;
* petits entrepreneurs ;
* personnes immunodéprimées ;
* personnes critiques des mesures ;
* personnes endeuillées ;
* personnes exclues du numérique ;
* organismes communautaires ;
* citoyens méfiants envers les autorités.

### Exercice

L’étudiant choisit trois voix contrastées.

Exemple :

| Voix              | Parole possible                                  | Ce qu’il faut éviter               |
| ----------------- | ------------------------------------------------ | ---------------------------------- |
| Soignant          | “On était débordés.”                             | réduire toute la crise à l’hôpital |
| Parent            | “Les fermetures ont brisé l’équilibre familial.” | traiter cela comme secondaire      |
| Personne critique | “On ne nous a jamais écoutés.”                   | la disqualifier automatiquement    |

### Point de méthode

Le chapitre ne demande pas :

> Qui avait raison ?

Il demande :

> Qu’est-ce que chaque parole révèle, et qu’est-ce qu’elle ne permet pas encore de conclure ?

### Phrase à retenir

> Une crise ne se comprend pas en écoutant seulement les autorités, ni seulement les opposants. Elle se comprend en tenant ensemble les paroles, les silences, les conflits et les contextes.

## 05. Distinguer faits, hypothèses et interprétations

### Rôle du cas

C’est un chapitre central pour un sujet polarisé.

Le cas COVID contient énormément de mélanges entre :

* faits ;
* hypothèses scientifiques ;
* interprétations politiques ;
* décisions administratives ;
* jugements moraux ;
* accusations ;
* incertitudes.

### Tableau appliqué

| Énoncé                                        | Classement possible                  | Vérification nécessaire                             |
| --------------------------------------------- | ------------------------------------ | --------------------------------------------------- |
| “Les consignes ont changé plusieurs fois.”    | Fait, si documenté                   | retrouver les consignes datées                      |
| “Les autorités ont menti.”                    | Accusation / interprétation          | préciser qui, quand, sur quoi, avec quelles preuves |
| “Les mesures ont sauvé des vies.”             | Hypothèse ou conclusion à documenter | sources, modèles, comparaisons                      |
| “Les mesures ont causé des dommages sociaux.” | Hypothèse ou fait selon données      | santé mentale, école, économie, isolement           |
| “Les critiques étaient irresponsables.”       | Interprétation morale                | distinguer critiques fondées et désinformation      |
| “Il fallait fermer les écoles.”               | Décision proposée                    | comparer options et impacts                         |
| “La confiance publique a diminué.”            | Hypothèse ou fait mesurable          | sondages, participation, comportements              |

### Production

L’étudiant classe 10 énoncés liés au Grand Dossier COVID.

### Phrase à retenir

> Dans une crise polarisée, distinguer les catégories n’affaiblit pas la critique ; cela la rend plus forte.

# Partie 2 — Explorer les solutions avant de choisir

## 07. Ne pas courir vers la première solution

### Rôle du cas

La crise COVID permet de montrer le danger des solutions automatiques.

Solutions rapides typiques :

* tout fermer ;
* tout ouvrir ;
* tout centraliser ;
* tout laisser aux individus ;
* censurer les critiques ;
* suivre seulement les experts officiels ;
* rejeter toute expertise officielle ;
* imposer une solution uniforme à tous les contextes.

### Exercice

L’étudiant identifie une solution rapide et la ralentit.

Exemple :

> “Il fallait tout fermer.”

Questions :

* Qu’est-ce que cette solution protège ?
* Qu’est-ce qu’elle endommage ?
* Qui est affecté ?
* Quelle alternative aurait dû être comparée ?
* Quelle donnée manque ?
* Quelle voix manque ?

### Phrase à retenir

> Dans une crise, la première solution visible est souvent celle qui réduit l’angoisse, pas nécessairement celle qui réduit le dommage total.

## 10. Choisir sous contrainte de temps

### Rôle du cas

La pandémie montre qu’une décision doit parfois être prise avant que tout soit connu.

Le chapitre enseigne :

* décider sans certitude totale ;
* rendre la décision révisable ;
* expliciter les risques ;
* annoncer les critères de révision ;
* reconnaître les incertitudes.

### Formule appliquée

```text
Nous retenons l’option ___ parce que ___.
Nous reconnaissons que cette option comporte les risques suivants : ___.
Nous ne retenons pas ___ pour l’instant parce que ___.
Cette décision devra être révisée si ___.
Les impacts à surveiller sont ___.
Les personnes à consulter sont ___.
```

### Exemple

> Nous retenons une stratégie de protection ciblée, ventilation, communication transparente et relais communautaires, parce qu’elle cherche à réduire les risques sanitaires sans produire des dommages sociaux excessifs. Cette décision devra être révisée si les hospitalisations augmentent, si les groupes vulnérables ne sont pas rejoints ou si les effets secondaires deviennent trop lourds.

### Phrase à retenir

> En crise, une décision responsable n’est pas une décision certaine ; c’est une décision explicable, surveillée et révisable.

# Partie 3 — Agir en prévoyant les impacts

## 12. Transformer une décision en action

### Rôle du cas

Montrer qu’une décision publique ne devient pas automatiquement une action coordonnée.

### Exemple

Décision :

> Améliorer la communication de crise.

Action réelle :

* qui rédige ?
* qui valide ?
* qui traduit ?
* qui diffuse ?
* qui répond aux questions ?
* qui vérifie la compréhension ?
* qui corrige les messages ?

### Tableau appliqué

| Action                              | Responsable                  | Ressources              | Échéance     | Suivi              |
| ----------------------------------- | ---------------------------- | ----------------------- | ------------ | ------------------ |
| créer fiche claire des consignes    | équipe santé + communication | données validées        | 48 h         | retours terrain    |

| publier justification des décisions | direction                    | documents, critères     | hebdomadaire | questions reçues   |

### Phrase à retenir

> Une décision de crise sans responsabilités visibles devient une consigne flottante.

C’est une épreuve de lucidité : savoir si une société peut regarder ses erreurs sans les maquiller, protéger les personnes sans infantiliser le public, décider sous contrainte sans écraser le débat, et transformer la douleur collective en mémoire active.

# Formule à fixer dans le manuel

```markdown
## Cas filé — Le Grand Dossier COVID

Ce manuel utilise le Grand Dossier COVID comme cas filé critique.

Le but n’est pas d’imposer une conclusion unique sur la pandémie, mais d’apprendre à examiner une crise où les sociétés ont dû connaître, choisir, agir et se souvenir sous pression.

Le cas assume une hypothèse forte : la gestion de la pandémie a révélé des défaillances importantes de préparation, de communication, de proportionnalité, d’écoute, de suivi des impacts et de mémoire institutionnelle.

L’étudiant devra donc travailler avec rigueur : documenter les accusations, distinguer faits et interprétations, comparer les options, prévoir les impacts, reconnaître les erreurs et transformer les dossiers dormants en mémoire utile.
```

C’est le bon cas filé pour UCKK : critique, polarisant, systémique, mémorable, et parfaitement aligné sur la méthode du manuel.
